## 2. The assemblage decision (KEEP SEPARATE) [T-04]
- **No merger rule** (docrag, UDO §14.3.2): each lot of record separately buildable with one SF
  dwelling if it meets §14.3.2 (Zone X ✓, ≥30 ft wide, pre-ordinance PB43 ✓, accepted street OR
  §12.2.2 access, water+wastewater available, use permitted). Fallback if a lot fails: BoA minor SUP.
- **Keep separate → up to TWO homes, no impervious cap.** Recombine → ONE home + impervious cap. →
  **Keep separate.** Verify in writing with Durham Planning. Duplex still barred in RR.
