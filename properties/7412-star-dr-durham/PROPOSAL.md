# DEVELOPMENT PROPOSAL ANALYSIS -- 7412 Star Dr + 212 Pine Dr (Herring two-lot assemblage)

> The plan tested against constraints (UNDERSTANDING), market (MARKET), trajectory (AREA).
> **Last updated: 2026-07-08** · Stage: pre-acquisition.

## The proposal
Buy **BOTH** Herring lots from the same seller — 212 Pine Dr (Oak Hill Blk C Lots 3&4, REID 143264)
+ 7412 Star Dr (Lots 5&6, REID 143262), 1.84 ac contiguous under one deed — **build single-family
home(s) to LIVE IN and sublease room(s) on Airbnb**. Explore STR angles / who to cater to; leverage
the Valora Oak wedding venue across Stagecoach Rd, Jordan Lake, and ~10-min UNC Chapel Hill proximity.

## The one decision that reframes everything: KEEP SEPARATE, don't recombine [T-04]
docrag confirms Durham UDO has **no contiguous-common-ownership merger rule**; each legally-established
lot of record is separately developable with one single-family dwelling under **§14.3.2**. So:
- **KEEP the two parcels SEPARATE → up to TWO by-right single-family homes** (one each), no watershed
  impervious cap as-is. ✅ This is the plan.
- **RECOMBINE into one 1.84-ac lot → only ONE home** (still under the 2–3 ac watershed RR minimum)
  **AND** triggers the Jordan Lake impervious/BUA cap. ❌ Strictly worse. Do not recombine.
- Duplex/two-family still barred in RR (use not permitted) — scaling is via more ROOMS, not more units.

## Buildability gates (SAME as 212 Pine, now DOUBLED — apply to each lot)
1. **Septic (make-or-break #1).** Both lots sit on **White Store sandy loam** (confirmed on 7412 by
   point-in-polygon, T-07) — USDA "poorly suited for conventional septic" (Triassic clay, high
   shrink-swell). Conventional drainfield likely fails perc; engineered/alt system (LPP/drip/fill) if
   permittable at all, at ~$15–40K **each**. **Two homes = two systems that each must perc.** RED FLAG.
   Septic capacity also **caps bedroom count** → fix perc before fixing the STR bedroom program.
2. **Road/access (#2).** Star Dr / Pine Dr are dedicated but **UNDEVELOPED ROW**; building requires an
   ~20-ft NCDOT-standard road at the owner's expense (~$40–100K+). Serving **both** lots may share the
   road — an argument FOR buying both (amortize the dominant cost across two homes). [212-pine T-08/T-09]
3. **Watershed/lot.** Falls/Jordan Lake Protected-Area-B overlay; one home per lot fine; no impervious
   cap as-is (only if recombined). [T-04, 212-pine T-15]
4. **Utilities:** well(s) ~$10–25K each (or shared); no city service. Verify fiber/Starlink (mid-term
   segment depends on internet). [T-06]

## Residual / max-bid model (planning-grade, ranges)
**Owner-occupied framing:** value = homes you'd occupy/hold; STR/mid-term income *offsets* cost, it
does not by itself justify the build as an investment. The wedding-venue moat + medical/mid-term floor
make the income more defensible here than at 212-pine-alone, but it's still a residence play.

- **Combined finished-lot value (contingent-buildable, IF both perc + access clear):** ~$80–180K
  (2 × $40–90K). **If only one percs:** ~$40–90K (one lot) + near-$0 (the other). **If neither percs:**
  near $0 (unbuildable). Assessed today $58,880 combined; seller basis ~$16,000. [T-02, MARKET]
- **All-in per home:** land + ~1,800–2,400 sf @ ~$200–275/sf ($360–660K) + engineered septic $15–40K
  + well $10–25K + share of road $20–50K + watershed stormwater. **Two homes ≈ ~$0.8–1.3M all-in.**
- **Income offset:** home #1 lockoff suite ~$24–38K/yr mid-term (or STR-premium-weekend upside);
  home #2 (if built + operated) similar or more as the wedding specialist. Net after tax/PM/cleaning:
  a meaningful offset to carry, **not** a standalone investment yield.
- **Max bid on the LAND (both lots), disciplined:** condition ANY offer on **perc + access**;
  contingent value caps a rational bid near **~$80–180K combined** for the pair (less if you carry the
  full road/septic risk). The wedding-venue adjacency adds resale/《STR》appeal but **no land-value
  premium** — it adds an income angle, not dirt value.

## Alternatives (ranked)
1. **Buy both, keep separate, build home #1 now + hold lot #2** — recommended IF it percs. Live in #1
   with the flex lockoff suite; build #2 later as the wedding-overflow house or spec-sell when ready.
   Amortizes the road across two lots; preserves optionality.
2. **Buy both, build home #1 only, land-bank #2** — minimal carry (~$1.7K/lot tax), bet on
   RTP-corridor appreciation; build/sell #2 later.
3. **Buy 7412 only (skip 212 Pine)** — one home, one septic risk; loses the two-home upside + the
   road-cost-sharing. Only if the seller won't deal on both or only one lot percs.
4. **Spec-build to SELL** (no STR) — normal rural-build economics, no R-1/SUP friction; still gated by
   perc/access. Fallback if you don't want to live here.
5. **Walk** — if neither lot percs affordably, or the road cost + land ask exceed the contingent value.

## Verdict
**Plausibly VIABLE as an owner-occupied two-lot play — proceed to the buildability checks, do NOT
recombine, and condition any offer on septic + access.** The assemblage's real value is TWO separate
by-right lots (not recombination), the road cost shares across both, and the wedding + university +
medical demand stack makes the STR/mid-term income genuinely more attractive here than the 212-pine-
alone read. But the deal still lives or dies on the **same make-or-break gate as 212 Pine — septic on
White Store clay — now doubled.** Pay $16K-basis-aware, contingent-buildable prices, not the extrapolated
~$140K/lot ask, for lots whose buildability is unconfirmed.

## What would change the verdict
- **Both lots perc affordably** (or already have valid soil evals — request from seller) → viability
  jumps; two-home plan is real.
- **Neither percs / engineered system uneconomic** → walk (or buy one only if it percs).
- **Road cost comes in low** (reduced rural section approved, shared across two lots) → improves all cases.
- **Seller accepts a two-lot, perc-contingent price near contingent value** → strong buy.
