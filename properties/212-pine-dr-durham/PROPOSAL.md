PERMANENT RESIDENCE, and rent out a room (later maybe more) on Airbnb** — an owner-occupied
homestay, not a non-owner STR investment.

## Reality check vs. what we found

## Residual / economics (rough, planning-grade)
**STR income does NOT drive value here.** Gross STR ~**$20–25K/yr** (mid), $15–20K yr-1; net of 6%
occupancy + 7.5% sales tax, PM (~20%), cleaning, utilities, insurance, furnishing → **~$8–14K/yr net**,
against a **new-build all-in of ~$450–650K** (land + ~1,800–2,400 sf @ ~$200–275/sf + well ~$10–25K +
septic ~$15–40K + any R-1 commercial premium + access/driveway + watershed stormwater). That's a
**~1.5–3% gross-of-debt yield — it does not pencil** as an income STR; the exit would rely on the
*home's resale value*, not the rental.

**Max bid on the LAND:** as a normal single-home rural buildable lot (IF perc + access + watershed
clear), finished-lot value is on the order of **~$40–90K** (assessed $29,440); **the STR angle adds
NO premium** — it adds cost (R-1) + permitting risk (SUP) for little income. If perc or access fails,
land value ≈ **near zero** (unbuildable).

## Verdict (REFRAMED T-06/T-07 — owner-occupied homestay)
**Plausibly VIABLE — proceed to the buildability checks.** As an owner-occupied residence + rented
room: permitting is the friendly path (homestay/B&B, owner-occupancy met), build is IRC (no R-1
premium), and the "does STR income cover the build?" test no longer applies (it's the home you'd live
in anyway; room income is a bonus). **The deal now turns on:**
1. **Septic** — soil testing is DONE (get the results, T-08); a pass clears gate #1 cheaply.
2. **Road** — access is legal but the ROW is UNDEVELOPED → must **build an ~20' NCDOT-standard road**
   (T-08). The **dominant cost line** — get a civil quote (cf. 1621 Clermont's road problem).
3. **Watershed/lot** — one home fine; NO impervious limit as-is (only if lots recombined, T-08).
4. **Price** — **$140K ask vs ~$40–90K for a contingent-buildable rural lot.** Condition any offer on
   perc + access; if it percs, has access, and you value the Corps/Jordan-Lake privacy for a home,
   the premium is a personal call — but don't pay $140K for an unconfirmed lot.
5. **Do you want to live here?** — rural, car-dependent (Walk Score 3), but private/wooded by the lake,
   4.6 mi to Southpoint, 1.9 mi to I-40. That's a lifestyle fit question, not a spreadsheet one.

*(The earlier "lean WALK" applied ONLY to the non-owner whole-house STR investment — not this plan.)*

## Alternatives (ranked)
1. **Walk** — the STR thesis doesn't survive; default.
2. **Owner-occupied home + occasional/room STR (B&B-form)** — more permittable (IRC build, possibly
   L/minor-SUP), but that's a *residence*, not an investment STR — different goal.
3. **Build a spec home to SELL** (not STR) — normal rural-build economics; still gated by perc/access;
   no STR premium, no R-1 cost. Only if the numbers work as a straight build-and-sell.
4. **Hold land** — minimal carry ($1.7K-ish tax), bet on RTP-corridor appreciation (AREA base case).
   Speculative, no income.

## What would change the verdict
- Durham Planning says a whole-house STR **is** permitted by-right/administratively in RR (unlikely). 
- Perc passes cheaply + Pine Dr is NCDOT-maintained + lot is "All Other Locations" (not watershed) →
  buildability easy. Even then, STR income still doesn't justify the R-1 build — so it flips to a
  *spec-home-for-sale* play, not an STR.
